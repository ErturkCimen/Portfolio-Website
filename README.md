# Ertürk Çimen — Personal Portfolio Website

A clean, responsive personal portfolio website built with **pure HTML and CSS** — no frameworks, no libraries, no dependencies.

🌐 **Live site:** [erturkcimen.github.io/Portfolio-Website](https://erturkcimen.github.io/Portfolio-Website)

---

## About

This is my personal portfolio site where I showcase my projects, technical skills, and international experience (Erasmus+ exchange in Poland).

Built as a real project for my CV — and also listed *as* a project on the site itself.

---

## Features

- Sticky navbar with blur effect
- Blinking cursor animation in the hero section
- About section with stat cards (countries visited, graduation year, etc.)
- Skills grid with hover effects
- Projects section linking to GitHub repos
- Erasmus+ experience highlight section
- Contact section with working Gmail compose link
- Mobile-responsive with hamburger menu
- Zero external dependencies — runs from a single `.html` file

---

## Tech Stack

| Technology | Usage |
|---|---|
| HTML5 | Structure and semantics |
| CSS3 | Styling, layout, animations |
| CSS Grid | Page layout and card grids |
| Flexbox | Navigation and component alignment |
| CSS Custom Properties | Consistent color/spacing system |

## Run Locally

No build step needed. Just open the file:

```bash
git clone https://github.com/ErturkCimen/Portfolio-Website.git
cd Portfolio-Website
open index.html   # or double-click the file
```
